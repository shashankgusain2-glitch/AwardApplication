# templates/judging/

**Judge pages** (built by `apps/judging/views.py`).

| File | Page |
|---|---|
| `assignments.html` | The judge's own assignments: reference, award, round, status; Accept or Decline, Grade, or View my scores. On blind awards the applicant shows as "Hidden for blind judging" |
| `score.html` | One report as the judge may see it, and the scorecard (1–10 per criterion, comments, feedback). Save midway or submit; after submitting, ask to change and change with a reason. Shows why names are hidden or shown for this round, and the permanent list of score changes |
