# templates/judging/

**Judge pages** (built by `apps/judging/views.py`).

| File | Page |
|---|---|
| `assignments.html` | The judge's own real assignments: reference, award, round, status, Accept or Decline. On blind awards the applicant shows as "Hidden for blind judging" |
| `score.html` | One entry and its scorecard (1–10 per criterion). Shows why names are hidden or shown for this round |
