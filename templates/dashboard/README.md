# templates/dashboard/

**Leadership pages** (built by `apps/dashboard/views.py`).

| File | Page |
|---|---|
| `overview.html` | Real counts for the whole event: reports submitted, being judged, waiting for approval, score-change requests, and each award's manager and progress |
| `awards.html` | Awards and managers: every award with its manager and staff, + New award, and a Team link per award |
| `people.html` | Add a person (staff, award manager, judge, leader) and the list of everyone, with deactivate / reactivate / resend invite |
| `results.html` | Scored reports, best first, with every judge's total and feedback; Approve or Reject |
