# templates/entries/

**Applicant pages** (built by `apps/entries/views.py`).

| File | Page |
|---|---|
| `dashboard.html` | The applicant's applications with progress, and awards they can enter |
| `organisation.html` | Organisation profile: GSTIN, PAN, sector, size, turnover, contact |
| `application_form.html` | One section of an award's form, with the section list, progress and save buttons; read-only once submitted |
| `application_status.html` | Timeline of where the entry is |
