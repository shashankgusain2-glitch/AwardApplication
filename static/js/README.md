# static/js/

**Small bits of page behaviour.** Django builds the pages on the server, so very little JavaScript is needed.

| File | What it does |
|---|---|
| `main.js` | Opens the **mobile menu**; shows a short **"demo" message** for buttons that don't save yet; on Award settings, **disables blind judging** instantly when every round is in person (the server checks this too) |
