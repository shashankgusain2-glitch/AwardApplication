# static/css/

**The look of the whole website.**

| File | What it does |
|---|---|
| `main.css` | The complete design in one file: **colours** (navy, gold, teal) set once at the top, then the public site (header, hero, footer), the portals (sidebar, top bar), and shared pieces (buttons, cards, status badges, tables, forms, switches, score buttons, timelines, progress bars). Also adjusts layouts for phones |

To change a colour everywhere, change its variable at the top of `main.css`.
