# static/

**Files sent to the browser as they are: styles and scripts.**

## What it does in the application

| Folder | What it holds |
|---|---|
| [css/](css/) | How every page looks |
| [js/](js/) | Small bits of page behaviour |

Pages link to these files with a version number (`?v=...`) that changes when a file changes, so browsers don't use an old cached copy.
