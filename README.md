What I understood about the project

An industry body in India runs about 80 award programmes, and each one uses a different website or portal. They want one platform that runs all of them, where staff can set up a new award without a developer.

In 10 days I will build a small working demo of a  system running two Awards that work differently, where staff can also set the new Awards without changing code. The platform must follow four rules:

1.Blind judging: jury members can't see who applied
2.Conflict of interest: jury members never get an application they have a conflict with
3.Score audit trail: the system records who changed a score, and why(compulsory)
4. Data form old platforms should work correctly on the new platform (# has not looked into it)


//Key finding

1."Moving to one platform" is five problems: people, organisations, award setup, history, and habits (old URLs and emails).
2. Applicants are organisations, not individuals. This matters for rule 2 (conflict of interest), because two spellings of one company must be treated as the same.  like Tata Power and Tata Powe Delhi.
